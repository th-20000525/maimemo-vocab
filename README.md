# 考研红宝书 · 背单词（墨墨卡片）

单页应用，在线打开即可背词。

## 两种模式

- **卡片背词（默认）**：整本 7069 词按编号从头到尾**循环**。只有两个按钮：
  - **认识**：记为已会，以后不再出现。
  - **熟悉**：本轮整本过完后，下一轮从头按顺序再看。
- **列表核对**：按批次（默认每批 1000 词）列表勾选已会，「删除已勾选」会进入下一批并上传云端。

## 每日 1000 词

- 每天最多刷 **1000 个词**（卡片上两个按钮、列表删除勾选都计入）。
- 第二天从上次停下的位置接着背；页面上显示当前是第几轮、背到第几个。

## 进度与同步

- 进度保存在浏览器本地。
- 设置**同步码**后：打开页面自动**拉取云端**；背词后会自动**上传云端**（跨设备一致）。

## 卡片快捷键

- 空格：显示释义  
- `1` 熟悉 · `2` 认识

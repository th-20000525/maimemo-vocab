# 考研红宝书 · 背单词（墨墨卡片）

单页应用，在线打开即可背词。

## 短语牌组（默认卡片）

默认卡片模式背的是 **《短语三档手册》2462 条**（`phrase-guide.js`）：

| 档 | 条数 | 怎么背 |
|----|------|--------|
| A 可推 | 110 | 动作＋方向推法 + 例句 |
| B 多义 | 7 | 看清分支，靠例句分路 |
| C 整记 | 2345（含 8 条★高频） | 整条＋例句；记法为「中心词／拆解」本质理解 |

学习顺序：A → B → C★ → C。  
升 `PROGRESS_EPOCH` 后本地/云端旧「已会」会自动清空，请 **Ctrl+F5** 后从头背。

## 作文短语

主页带 `#phrase` 时可查看作文短语对照列表（① 图表 · ② 图画 · ③ 轻养生 · ④ 人生哲理 · 万能句型，共 73 条）。

## 两种模式

- **卡片背词（默认）**：按上面的 2462 条短语循环。
  - **认识**：记为已会，以后不再出现。
  - **熟悉**：本轮跳过，下一轮再遇。
- **列表核对**：按批次勾选已会（单词列表，已非主路径）。

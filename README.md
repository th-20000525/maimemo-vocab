# 考研红宝书 · 背单词（墨墨卡片）

单页应用，在线打开即可背词。**默认每批 1000 词**（「从–到」范围，下一批自动 +1000）。

## 两种模式

- **卡片背词（默认）**：看英文 → 点卡片显示释义 → 只有两个按钮：**认识**（已会，不再复习）、**熟悉**（本批其它词都过完后，按顺序再复习）。
- **列表核对**：按批次列表勾选已会，「删除已勾选」会进入下一批并上传云端。

## 进度与同步

- 进度保存在浏览器本地。
- 设置**同步码**后：打开页面自动**拉取云端**；删除/认识后会**上传云端**（跨设备一致）。

## 每日 1000 词

- 每天最多刷 **1000 个词**（卡片上两个按钮、列表删除勾选都计入）。
- 满 1000 后当天不再加新卡。

## 卡片快捷键

- 空格：显示释义  
- `1` 熟悉 · `2` 认识
